# جارویس شهروز (نسخه اندروید / وب‌اپ نصب‌شدنی)

این پروژه یک PWA فارسی است: با Chrome اندروید باز می‌شود و از منوی مرورگر می‌توان آن را روی صفحه اصلی نصب کرد. رابط در GitHub Pages میزبانی می‌شود؛ مغز هوش مصنوعی در سرویس جداگانه Render اجرا می‌شود.

## امکانات نسخه دوم
- انتخاب صدای فارسی مردانه در اولویت (اگر صدای مردانه فارسی روی گوشی نصب/در دسترس باشد)
- بیدارباش «Hey Jarvis» با دکمه روشن/خاموش
- فرمان‌های محدود برای بازکردن YouTube، WhatsApp، Telegram، Instagram، Chrome و تنظیمات اندروید
- جستجوی وب با بازکردن نتایج Google در مرورگر
- آب‌وهوا با موقعیت مکانی گوشی و سرویس Open-Meteo
- تیتر خبرهای فارسی از Google News RSS
- حافظه دائمی با اتصال اختیاری Supabase
- رابط راست‌چین و تم علمی‌تخیلی
- تشخیص گفتار فارسی با Web Speech API (پشتیبانی مرورگر وابسته است)
- خواندن پاسخ با صدای فارسی دستگاه، در صورت وجود صدای فارسی
- پاسخ اختصاصی به «کی تو رو ساخته؟» با عبارت «شهروز منو ساخته»
- اتصال به OpenAI از سمت سرور؛ کلید API هرگز در فایل‌های وب قرار نمی‌گیرد

## راه‌اندازی حافظه دائمی (پیشنهادی)
1. در [Supabase](https://supabase.com) یک پروژه بساز.
2. در SQL Editor این دستور را اجرا کن:
   ```sql
   create table if not exists public.jarvis_memory (
     id bigint generated by default as identity primary key,
     note text not null,
     created_at timestamptz not null default now()
   );
   alter table public.jarvis_memory enable row level security;
   ```
3. در Render → Environment، متغیرهای `SUPABASE_URL` و `SUPABASE_SERVICE_ROLE_KEY` را وارد کن. مقدار Service Role فقط باید در سرور Render بماند؛ هرگز آن را در GitHub یا کد مرورگر قرار نده.
4. اگر این دو متغیر تنظیم نشوند، حافظه به فایل محلی سرور می‌رود که در سرویس رایگان Render ممکن است بعد از restart/redeploy از بین برود. برای ماندگاری واقعی از Supabase استفاده کن.

- رابط راست‌چین و تم علمی‌تخیلی
- تشخیص گفتار فارسی با Web Speech API (پشتیبانی مرورگر وابسته است)
- خواندن پاسخ با صدای فارسی دستگاه، در صورت وجود صدای فارسی
- پاسخ اختصاصی به «کی تو رو ساخته؟» با عبارت «شهروز منو ساخته»
- endpoint حافظه `/remember` برای ذخیره یادداشت‌ها
- اتصال به OpenAI از سمت سرور؛ کلید API هرگز در فایل‌های وب قرار نمی‌گیرد

## ۱) ساخت مخزن GitHub
1. در GitHub یک مخزن جدید بساز؛ مثلاً `jarvis-shahrooz`.
2. فایل‌های این پروژه را داخل مخزن بارگذاری کن (Upload files) یا با Git push کن.
3. فایل workflow از قبل داخل `.github/workflows/pages.yml` قرار دارد و پوشه `web` را منتشر می‌کند.
4. در مخزن به Settings → Pages برو و در بخش Build and deployment، گزینه Source را روی **GitHub Actions** بگذار.
5. به تب Actions برو؛ پس از پایان اجرای Deploy، آدرس GitHub Pages در Settings → Pages نمایش داده می‌شود.

## ۲) آنلاین کردن مغز در Render
1. در Render وارد حساب شو و New → Blueprint انتخاب کن؛ مخزن GitHub را وصل کن. فایل `render.yaml` در ریشه مخزن، سرویس و پوشه بک‌اند را تنظیم می‌کند. اگر Blueprint در دسترس نبود، Web Service بساز و Root Directory را `backend` قرار بده.
2. Build Command: `pip install -r requirements.txt`
3. Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
4. در Environment Variables مقدار `OPENAI_API_KEY` را وارد کن. در صورت نیاز `OPENAI_MODEL` را هم تنظیم کن.
5. پس از Deploy آدرس سرویس شبیه `https://jarvis-shahrooz-api.onrender.com` می‌شود.

## ۳) وصل کردن سایت به بک‌اند
فایل `web/app.js` را باز کن و مقدار `API_BASE` را از `https://YOUR-BACKEND.onrender.com` به آدرس واقعی Render تغییر بده. سپس تغییر را در GitHub commit کن.

## ۴) نصب روی گوشی اندروید
1. آدرس GitHub Pages را با Chrome اندروید باز کن.
2. منوی سه‌نقطه Chrome → Install app یا Add to Home screen.
3. آیکون جارویس روی صفحه اصلی ظاهر می‌شود.
4. برای میکروفون و موقعیت مکانی، مجوزهای Microphone و Location را به سایت بده. HTTPS لازم است. برای بیدارباش، دکمه Hey Jarvis را فعال کن.

## ۵) قابلیت‌های اندروید و محدودیت‌ها
- برای بیدارباش، صفحه جارویس باید باز و روشن بماند و کاربر باید یک بار دکمه «Hey Jarvis» را لمس و مجوز میکروفون را تأیید کند. مرورگر اندروید معمولاً شنود دائمی در پس‌زمینه یا وقتی صفحه قفل است را تضمین نمی‌کند؛ برای چنین قابلیتی باید اپ بومی Android با سرویس foreground و مجوزهای مربوط ساخته شود.
- بازکردن برنامه‌ها فقط برای چند برنامه/پیوند پشتیبانی‌شده پیاده‌سازی شده است. وب‌اپ اجازه کنترل آزاد همه برنامه‌ها، تماس‌ها، پیامک‌ها، تنظیمات سیستمی یا دسترسی مخفی به گوشی را ندارد.
- صدای مردانه فقط در صورتی انتخاب می‌شود که صدای فارسی مردانه در موتور گفتار گوشی موجود باشد؛ در غیر این صورت از صدای فارسی پیش‌فرض استفاده می‌شود.
- جستجو نتایج را در Google باز می‌کند؛ خبرها از RSS گوگل نیوز و آب‌وهوا از Open-Meteo می‌آیند.

## ۶) تست
- «سلام جارویس»
- «کی تو رو ساخته؟» ← باید بگوید «شهروز منو ساخته.»
- برای تست API یک سؤال عمومی بپرس.
- برای ذخیره یادداشت بگو یا بنویس «یادت باشه که جلسه پنجشنبه ساعت ۱۰ است». جارویس آن را به endpoint `/remember` می‌فرستد.

## نکات مهم
- GitHub Pages فقط فایل‌های ثابت را میزبانی می‌کند؛ اجرای Python و نگهداری کلید API روی GitHub Pages ممکن نیست. به همین دلیل بک‌اند جداگانه روی Render است.
- هرگز `OPENAI_API_KEY` را در `web/app.js`، HTML یا مخزن GitHub قرار نده.
- سرویس رایگان Render ممکن است پس از مدتی بی‌استفاده‌بودن به خواب برود و اولین درخواست بعدی دیرتر پاسخ دهد.
- حافظه فعلی روی دیسک سرویس است؛ در سرویس‌های رایگان ممکن است با redeploy یا تغییر نمونه از بین برود. برای حافظه دائمی چندکاربره، دیتابیس پایدار لازم است.
- این نسخه یک PWA قابل نصب روی اندروید است، نه APK بومی. اگر APK لازم داری، می‌توان آن را بعداً با Capacitor یا Kotlin به اپ بومی تبدیل کرد.
